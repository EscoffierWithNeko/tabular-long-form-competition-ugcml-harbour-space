# 竞赛技术文档与实验报告归档 (Documentation Archive)

本目录归档了在 Kaggle `tabular-long-form-competition-ugcml-harbour-space` 房源价格预测竞赛全生命周期中产出的核心技术报告、数据审计记录与全流程实验日志。这些文档忠实记录了从最初的基线探索（CV 0.30512）到最终突破性登顶（CV 0.28109 / Public LB 0.27676）的每一轮实验依据、技术抉择与反思复盘。

---

## 一、归档文档清单与核心内容

### 1. `DATA_AUDIT_AND_LEAKAGE_CHECK.md` (数据审计与零泄漏验证报告)
* **定位**: 竞赛启动初期与特征工程重构阶段的权威数据防线。
* **核心内容**:
  * **赛题背景与数据集剖析**: 训练集 47,293 样本，测试集 11,971 样本，覆盖 Airbnb 真实房源多维异构属性。
  * **目标变量审计**: 价格严重右偏，评估指标为均方根对数误差 (RMSLE)，确立全局统一在 $\log(1 + y)$ 空间建模的标准。
  * **零数据泄漏 (Zero Leakage) 铁律制定**:
    * 严禁在全集上预计算 Target Encoding 或聚合统计；
    * 确立基于地理分层与价格分布的严格统一 10 折交叉验证体系 (`folds_10.npy`)；
    * 任何折内特征计算必须严格仅使用 `Train[fold_train_idx]` 拟合并变换到 `Train[fold_val_idx]` 和 `Test`。
  * **极端值与缺失值审计**: 对浴室文本 (`bathrooms_text`) 模糊表述、经纬度离群点、设施 JSON 格式等做出标准清洗准则。

### 2. `MODEL_EXPERIMENT_LOG.md` (全生命周期模型实验日志)
* **定位**: 记录整个团队全部迭代里程碑的实验技术日志。
* **核心内容**:
  * **Stage 1 (基线确立与单模突破)**: 5 折 LightGBM (0.30512) -> 10 折基座构建 -> 首次全模型融合 (0.30175)。
  * **Stage 2 (空间微网格与深度异构融合 - v2)**: 引入地理哈希聚类、高阶容量比率、PyTorch Tabular ResNet 与 CatBoost 原生文本模型，Level-2 融合打破 0.2830，斩获 Public LB 0.27755。
  * **Stage 3 (孪生微环境与多模态 Stacking - v3 巅峰登顶)**:
    * 发现并证实同房东在同微小街区同房型的强绑定定价先验，构建 `twin_3tuple` ~ `twin_5tuple` 复合键；
    * 引入 DART 随机树丢弃增强与 Huber 鲁棒损失 GBDT；
    * 研发贪婪前向特征优选算法与 SLSQP 约束凸优化加权器；
    * 验证集 CV 达成极致 **0.28109** (校准后 0.28099)，官方斩获 **Public LB 0.27676 (Ref 58373885)**。
  * **Stage 4 (高维语义空间与空间 KNN - v4 进阶探索)**: 预训练 BGE 稠密嵌入表示与 KD-Tree 空间近邻距离特征的探索与验证。
